# Méthodologie océan

## Sources

Copernicus Marine en priorité (licence commerciale OK, DOI obligatoire). NOAA OISST = analyse SST distincte, pas une bouée.

Produits d’autres fournisseurs **via** CMEMS : audit un par un.

## Affichage

- SST ≠ température in situ de plage.
- Profil : niveaux du produit, ou interpolation **étiquette INTERPOLATED**.
- Courants : vecteur vers où l’eau va (U/V).
- Vagues : Hs, direction, période selon produit.
- Glace : seulement si zone et produit.

## Anomalies SST

Toujours : produit + normale (période). Palette divergente centrée 0, distincte de la SST absolue.

## Limites

Pas d’aide à la navigation certifiée. Bathymétrie : future, source commercialement compatible seulement.

PoC 2 : Méditerranée occidentale, coordonnée marine réelle, variables réellement ingérées.
