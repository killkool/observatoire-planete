# Data quality
Examples: Tmin ≤ Tmax; RH 0–100 unless a documented convention; precip ≥ 0; wind speed ≥ 0; lat/lon valid.

Bounds are conservative. Extremes may be records: **flag, do not delete**. NULL is missing; 0 is measured zero.
